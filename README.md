# dsh-initalGithubRepository

适用于 DeepSeek Harness 的 Git 自动提交插件：每轮对话结束后自动生成规范化的提交信息并推送代码，支持自动检测仓库分支、从任意分支新建分支、工作区合并与 Rebase、会话内提交树版本回退，以及按会话与工作区配置仓库、分支、README AI 更新和提交前确认。

## 功能

- **自动提交**：每轮对话结束后生成规范化的 Commit 信息并推送代码；提交前会弹出确认，确认后隐藏窗口并在后台执行。
- **分支选择**：会话与工作区的分支改为下拉选择，自动读取仓库的本地分支与远程分支，并优先显示当前分支和默认分支；修改仓库地址后可点“刷新分支”重新读取。
- **新建分支**：在分支下拉中选择“＋ 新建分支…”，指定基于哪个分支以及新分支名；首次提交时从所选 base 创建并切换分支，如果远程已有同名分支则会拒绝创建，以避免覆盖。
- **工作区分支操作**：可把指定来源分支合并到工作区当前检出的分支，或把当前分支 rebase 到目标分支；发生冲突时会自动中止并报告冲突文件，操作前要求工作区干净，可选完成后推送（使用普通 push，不会自动 force push）。
- **版本回退**：在会话设置中打开提交树（最多展示最近 1,000 个提交），选择任意提交即可把项目内容恢复到该版本；回退通过一个新提交实现，不会 reset 或删除历史。
- **配置与凭据**：按会话与工作区分别配置仓库、分支、是否启用，以及是否由 AI 同步更新 README；GitHub 凭据安全存储。

更多实现细节见 [docs/DETAIL.md](docs/DETAIL.md)。
